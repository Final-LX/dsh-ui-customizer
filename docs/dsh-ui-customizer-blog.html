DeepSeek Harness（DSH）是 DeepSeek 推出的 AI 编程助手框架。通过 dsh web 启动浏览器界面，就能和 AI 对话、读写文件、执行命令、规划任务。功能强大，但外观一直比较朴素，默认只有浅色、深色、跟随系统三档。

我写了一个插件 dsh-ui-customizer，把界面定制做成了所见即所得的「主题设置面板」。改任何一项，界面立即生效，不需要改代码、不需要重启。

除了网页端插件，我还打包了一个桌面客户端，把 DSH 运行时和主题插件全部内置。下载安装就能用，适合不想折腾命令行的人。

它能改什么

四个维度加一处贴心设计，覆盖日常外观定制的全部诉求。

01

配色

5 个基础色（品牌、强调、成功、警告、错误），自动派生约 37 个语义 Token，另内置 8 套一键主题模板。

02

字体

界面字体与代码字体下拉选择（霞鹜文楷、思源黑体、JetBrains Mono 等），外加 80% 到 140% 的整体缩放。

03

背景

内置壁纸、上传图片（自动压缩到 1920px 宽 JPEG）、图片 URL，配面板通透度与毛玻璃强度。

04

圆角

0 到 24px 圆角滑杆，作用于按钮、输入框、下拉框、对话框，调小硬朗、调大圆润。

05

可读性设计

环境表面（主背景、侧边栏）跟随通透度变透明，露出背景图；覆盖层（对话框、菜单、输入框、提示气泡）固定保持约 94% 的不透明度。无论背景调得多透明，弹窗里的文字始终清晰可读。

网页端插件安装

如果不使用桌面端，也可以把插件安装到现有的 DSH Web profile。推荐使用仓库中的 PowerShell 脚本；需要 Node.js，完成后重启 DSH 服务。

  1. 1
    安装插件把插件装进 web profile
dsh plugin --profile web add "git+https://github.com/Final-LX/dsh-ui-customizer"
  1. 2
    登记 loader编辑 ~/.dsh/profiles/web/cordis.patch.yml
- insert: - id: ui-customizer name: dsh-ui-customizer
  1. 3
    重启并打开刷新后进入「设置」里的「DIY 主题」
npx @deepseek-ai/dsh web

没有 git 或 pnpm？在仓库根目录运行 .\install-web.ps1，即可复制插件并登记 loader。首次使用仍需按 DSH 的模型和 API key 引导完成配置。

实现原理

写给对技术细节感兴趣的读者。

01

覆盖设计 Token

用 ctx.theme.overrideTokens() 把 5 个基础色展开成约 37 个语义 Token 一次性覆盖，浅色、深色、跟随系统三档全部生效。

02

注入自定义 CSS

背景图、毛玻璃、圆角等 Token 体系外的样式，通过带标识的样式标签注入，与 Token 覆盖共同形成最终外观。

03

Slot 注册设置面板

向 settings.section 注册「DIY 主题」分区与具体设置项，机制上和官方「通用」「模型」分区完全一致。

04

前端图片压缩

上传背景图时用 Canvas 缩到 1920px 宽并转成 JPEG，控制存储体积，避免超大图片拖慢界面。
