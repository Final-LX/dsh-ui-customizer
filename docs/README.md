# 截图目录

把截图放在本目录，文件名与下表对应（README 会引用这些路径）。

| 文件名 | 截图内容 |
|---|---|
| `screenshot-overview.png` | 整体效果：应用某主题后的完整界面 |
| `screenshot-overview-2.png` | （可选）另一种配色模板的对比图 |
| `screenshot-entry.png` | 设置入口：设置面板左侧导航中的「DIY 主题」 |
| `screenshot-palette.png` | 配色面板：主题模板下拉 + 5 个取色器 |
| `screenshot-typography.png` | 字体面板：字体下拉 + 整体缩放 |
| `screenshot-background.png` | 背景面板：壁纸/上传/URL/通透度/毛玻璃 |
| `screenshot-components.png` | 组件面板：圆角滑杆 |

建议：宽度 1200px 左右，PNG 或 JPG，单张 < 500KB 为宜。
